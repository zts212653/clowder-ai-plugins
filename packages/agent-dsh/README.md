# DeepSeek Harness Desktop adapter

The adapter supplies a native system identity patch and translates DSH's ACP
session updates and terminal responses to Agent Adapter v1. The Host grants the
workspace, executable, private patch materialization and ACP process. A verified
native session ID is required for resume. The adapter keeps quota unsupported.

This alpha uses an isolated Desktop and loopback provider fixture. The default
Host launch grant, member login, tool approval, and desktop onboarding still
need product acceptance.
