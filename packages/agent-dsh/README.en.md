# DeepSeek Harness Desktop adapter

[Chinese](README.md)

The adapter supplies a native system identity patch and translates DSH ACP session updates and terminal responses to Agent Adapter v1. The Host authorizes the workspace and executable, writes the private patch and manages the ACP process. Resume requires a verified native session ID. The adapter reports quota as unsupported.

This alpha uses an isolated Desktop and a loopback model. The default launch grant, member login, tool approval and desktop onboarding still need product acceptance.
