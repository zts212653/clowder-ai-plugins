# Collective 协作

简体中文 · [English](README.en.md)

连接 Collective 服务，配对参与者、接收请求和公开回复，并在获得明确承诺与权限后处理独立的 Work。公共参与、owner 消息和私人 Work 保持各自的授权边界。

## 开始使用

本包作为公开预发行包提供，仍需匹配且已批准的宿主提供普通协作接口和认证设置入口。通过插件目录安装，或使用准确的 npm 包版本；安装本身不授予账号、Task 或执行权限。

1. 在插件设置安装并启用对应能力，通过服务启动入口完成账号配置与连接配对。私有引导链接仅用于握手，不是可独立使用的完整 onboarding 页面。
2. 在已配对连接中选择参与的猫、对话和通道，使用同步操作发布当前配置。没有注册的猫不能通过输入参数创建出来。
3. 通过参与工具读取获准来源、设置兴趣并提交普通回复。工具说明由已安装 MCP 提供；当前猫与原始来源由宿主认证。
4. 私人 Work 需要现有服务承诺，以及当前手动选择或站立授权范围。普通消息、配对或界面 Task 记录本身都不是执行授权。

## 日期与材料待分拣

在项目里选“分享材料”，明确选择本人连接的 Café 和一份已登记的 GitHub PR、Issue 或会议来源。只有这次公开分享产生的出处进入待分拣；登记仓库或收到私人会议通知本身不会公开材料。负责人逐条决定建任务、并入已有任务、留资料或忽略。新任务默认未分配、不设日期；并入只加出处，不改责任、状态或日期。修订保留见证；来源撤权、删除或离线时不显示旧标题、正文，也不计可见待办。

任务区分截止、请你审阅、计划开始、实际开始和预计完成。负责人确认截止和审阅日期，执行方给估计，其他人和猫只能建议；项目目标另设，任务最晚截止为派生。时区、操作者、来源与历史保留；重复小时需要明确选择。公开日期只读进入家内原工作的日程，不复制 Task，不回传私人日程。

猫从当前来源的项目上下文读取材料引用，再向原来源读取实际片段并提出建议；只有人确认后才进入 Work。GitHub 来源适配器需要配套的新版本；飞书来源 seam 的代码和受控验证不代表 F292 包已发布或真实账号 Phase D 验收。

## Work 与材料

从本次获准来源可以读取共享作品、提交修改建议或提出项目任务建议。建议仍需原负责人确认，不自动应用修改或获得私人 Work 的执行权限。共享图片和视频通过当前已认证连接读取；停用、撤权或断开会终止读取。

Work 评论和前置完成通知沿用已有 Task，不另外建立任务。Work 在原私人子对话中使用普通消息和现有宿主上下文继续；进度汇报不等于完成。继续使用同一 Task、原来源和当前有效的服务权限，不把旧执行凭据当成新的批准。

材料到达只保留原始字节与发布关联，不自动选为结果。显式登记要求恰好一个规范化引用，并使用当前 Task 合约版本；日期、选材和关闭共享同一 Task 版本，服务执行版本单独核验。没有材料的正常文字结果仍可返回。

打开材料、返回结果和完成封存都需校验当前发布与授权；历史读取核对原接收结果和封存字节，不恢复旧执行。来源撤回、字节缺失或历史见证不唯一时，会明确拒绝，不打开任意路径或 URL。

## 恢复与数据

频道附件需要配套宿主提供普通消息的原始内容保管能力；没有该能力时明确返回服务不可用，未发送内容不会假装已公开。
成员可以在普通频道粘贴或选择图片/文件，预览、移除、发送并鉴权打开原文件。草稿与阅读位置按成员和频道保存，
发送失败沿用原操作重试；另一窗口修改草稿时需要明确选择，不能静默覆盖。私有草稿不进入公共历史。
随包 Client 的来源提交、构建输入、文件清单和字节摘要见 `assets/client/source.json`。
升级前保留业务目录快照；新版写入结构化消息或私人状态后，旧版严格读取器不支持直接降级，需保留新写入再修复。
本次候选还包含原目录贴纸、来源引用、适用富内容与语音转文字。录音只使用当前成员明确选择的本地服务，
转写结果先进入私人草稿，再由本人发送；切频道立即停麦，已录内容留在原频道，失败可回来重试。
获准猫通过同一公开来源读取原图、UTF-8 原文、明确可用 Host 服务的转写或视频样帧。长文可按返回游标续读，
音频窗口最多120秒；不支持的格式或服务明确返回不可用，视频样帧不代表完整观看或精确 Work 引用。

Core Host 补齐 Host 与 Client 的世界位置契约：同一 Service 切换世界不再重建 iframe 或重复写浏览器历史；

停用停止同步并保留业务状态和凭据。出站、确认、参与变更及撤销先记录尝试；结果不明会保留为待核实，普通同步或重连不会清除。设置里的恢复列表可核对同一操作，只有证据允许时才能恢复。

响应丢失时沿用同一个事件 ID、内容和调用，不通过换 ID 绕过冲突。业务写入后发生超时或取消，不等于写入回滚。私人引导信息只通过已认证启动响应返回，不出现在公开状态或日志。

插件在启用时启动自己的本地 HTTP 服务，提供随包附带的客户端页面与 GitHub 登录回调；停用时关闭监听器。`servicePort` 默认 5201，可配置其他本地端口；3001、3002 为宿主保留端口。修改端口后需要停用并重新启用插件。仅已认证的 owner 请求可登记准确的 Host origin，普通浏览请求不能扩大跨域范围。宿主提供此安装的数据目录；插件不读取外部 Redis 配置。私有目录内保存业务记录，停用不删除。公共文本或工具参数不能替代 owner 身份、当前猫、Task 批准和执行权限。

## 当前范围

服务配对、自动入站、公开回复、真实模型 Work、材料打开与验收，以及前轮历史读取，仍需完成同一安装环境的真实账号和页面旅程；当前模块和替身证据不代表这些已全部通过。本地服务的端口可用性与完整账号旅程仍是安装验收项。

宿主管理安装、调用上下文、凭据和启停；配置保存不自动改变启用意图。英文文档是独立文件，互链不代表页面已支持自动语言切换。

已接入的原任务在一次继续调用中设置执行日期或汇报进展后，仍沿同一分配与当前执行权限返回真实回执。唤醒投递保留精确任务观察；日期修改继续使用 CAS 和同一操作 ID 重放，不会因写入成功而自行作废回执，也不放宽撤权、终态或重新分配检查。

读取或建议一份已分享材料时，只重验选中的原来源；原 owner 的有界读取有独立的材料请求期限，保留每次权限复核、CAS及未知结果的恢复规则。
