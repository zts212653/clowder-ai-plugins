# Google Cloud 配乐插件候选

[English](README.en.md)

这个目录目前只有连接进度组件，尚不是可以安装的完整插件。包保持私有，不在发布清单或插件目录中。

组件保存当前授权流程、所选 Cloud 项目、过期与取消结果。后续设置请求复用同一流程；切换项目后，旧回调不能取代新流程。记录保存在宿主提供的安装实例存储中，不保存访问令牌、刷新令牌或授权码。

回调接收器必须独立于一次设置请求运行，并持久承接自己的挑战与结果。组件只消费不透明完成引用；这里的 `ready` 表示接收器已有结果，不代表凭据已保存、费用已确认、插件已启用或已经生成音频。

真实 Google 回调接收器、现有授权复用、设置动作与秘密目标保存、插件声明、Cloud 生成和宿主授权文件交付仍需接线。当前测试只验证组件行为，不会打开浏览器、读取真实凭据或发起生成。已有有效授权应先检查和复用，不能因为安装插件而要求用户再次登录。
