# Tripo Studio 插件

[English guide](README.en.md)

读取已有 Studio 分享链接；在单独授权后，通过插件创建的工作页准备网页订阅生成任务。插件拥有业务适配代码，Clowder 负责安装、归档完整性与进程监督。

这是 **0.2.0 开发候选**。源码与测试通过不代表已经安装、发布或连接已登录订阅；通过此候选完成供应商真实生成、正式导出及四足动作的完整旅程仍待验证。

在设置的插件管理中安装已审查的不可变归档。Registry 安装需要实际发布的精确版本及目录完整性登记。同一插件的更新须使用 Host 支持的流程；插件不会直接改 inventory、覆盖已安装代码或自动卸载实例。

插件卡片的「本机组件」提供「刷新状态」。安装、打开设置和启用都不会自行准备本机组件、启动 Chrome 或授予网页权限。停用插件和关闭设置会取消未完成的状态检查。

## 读取已有模型

原有五个工具保持可用：

- `tripo_review_shared_model`：在独立匿名后台页面采集精确分享链接的多个视角。
- `tripo_status`：分别读取版本、本机组件连接与工作页授权状态。
- `tripo_prepare_chrome`：准备包内的扩展与本机组件，不代替 Chrome 原生确认。
- `tripo_collect_authorized_models`：只收集扩展中已明确授权的模型页。
- `tripo_export_selected`：验证并复制已收集且实际可用的预览 GLB，不替用户选模型，不请求供应商正式导出。

「只读」授权不能上传图片、提交生成或消耗积分。这个版本没有全账号资产清单或逐件账单工具。

## 网页订阅工作页候选

在扩展选择「生成与导出」并单独明确授权后，插件在同一 Chrome 登录会话中新开非活动 Studio 工作页，创建时使用 `active:false`。它不复制 Cookie 或 profile，不激活用户标签页。这项标签创建行为在隔离 Chromium 中验证过，不代表已证明 macOS 全程前台焦点不变。撤销会关闭插件创建的工作页并阻止后续操作，但无法取消供应商已经接收的任务。

- `tripo_workspace_status`：读取当前页面可见参数与登录状态，或导航到固定的生成、绑骨、动画入口。它不会执行 AutoRig 或写入动画。
- `tripo_prepare_generation`：上传已接受任务指定的一张正面图或正、左、右、背四张独立参考图，设置明确的可见范围和支持的 Smart Mesh 拓扑、面数，返回带摘要绑定的预览。此步骤不点生成；当前只支持已验证数量为一的提交，无法识别页面时停止。
- `tripo_submit_generation`：只提交与预览一致的任务一次，消耗网页订阅积分。点击前，本地任务记录和扩展均持久化本次尝试；回执丢失时记为 `submission_unknown`。重连、重启和重复准备同一任务键都不会自动重试；再次尝试前须先核对供应商作品。本候选没有自动重试或自动对账。
- `tripo_generation_status`：读取本地保留的尝试状态，不重试或猜测供应商已经生成完成。
- `tripo_request_official_export`：对身份已核实的选定模型和 GLB/FBX 格式，操作唯一可识别的导出菜单；控件或模型身份不明确就停止。
- `tripo_collect_official_export`：查询已跟踪下载，要求供应商来源与模型一致，检查真实字节并复制到指定目录，不覆盖已有文件。文件名或 URL 无法绑定模型时返回 `download_not_verified`，不能记作已导出或重新生成。真实供应商下载控件兼容性仍待验证。

GLB 的网格、骨架、动作和贴图信息来自已下载字节。局部坐标边界不是实物尺寸或世界尺寸；FBX 仍需 Blender 检查。网页目标面数不等于实测三角面数。绑骨和动画目前只覆盖固定入口读取与导航，四足兼容性、待机与行走质量仍需实际模型验证。

插件不调用另付费 Tripo API，不购买或升级套餐，不上传无关参考图。生成与导出、收集、检查、复制文件是分开的操作。准备前必须有已接受的用户任务和已确认参考图，提交前须审阅真实预览。

## 打包与验证

包使用原生 ESM 和 registry 完整性锁定的 `npm-shrinkwrap.json`，不依赖 Core 源码或打包器。新目录解包后无脚本安装锁定依赖，可启动全部十一个工具；新框架模块与设置状态操作也从实际归档加载验证。

`pnpm --filter @clowder-ai/tripo-studio test` 覆盖包契约、原生协议、分离授权、分块上限、单次提交持久化、预览变更、取消、文件字节与空白 consumer。`node packages/tripo-studio/test/workspace.browser.mjs` 使用仓库既有 Companion Playwright 工具链，在隔离的无头 Chromium 验证固定 DOM 操作及真实扩展启动；该检查中的供应商页面与权限回执是 fixture，不代表真实扣积分旅程。

模型、图片、任务记录和来源留在本机或调用者指定目录。包不包含用户图片、项目专用路径、浏览器 profile、Cookie 或生成模型。工具中的任务和来源引用是有界溯源字符串，不是凭据或可执行指令。
