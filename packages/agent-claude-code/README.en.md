# Claude Code Agent adapter

[Chinese](README.md)

This alpha runs Claude Code print-mode sessions through the Host Agent Adapter v1 contract. The Host grants version detection, a private identity file and a scoped native process. Prompts travel through stdin. The adapter projects native session IDs, assistant text, terminal outcomes and reported usage.

This carrier runs with tools and MCP disabled. The SDK, interactive carriers, login, model discovery and quota have separate product acceptance requirements.
