# Web / 源码部署

- 优先看 Host 实际给出的 API 日志目录。源码或编译启动的 API 通常写入 `data/logs/api`，也可由启动配置指定。浏览器界面错误或 HTTP 失败要和同一时间的 API 线索对齐；插件没有自动采集浏览器控制台。
- 只在所选项目验证了源码时定位实现。界面看 `packages/web/src`，API 和成员调用看 `packages/api/src`，运行启动方式看 `scripts`。先对比运行版本和 checkout，再确认某段实现是否在当前生效。
- 编译产物部署可以没有源码。先交付基于日志和版本的诊断，把需要对应版本源码才能确认的判断标为待核验。
