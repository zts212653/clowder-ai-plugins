# Kimi Code adapter

Adapts discovery, native session receipts, streamed events, and PTY quota output to the agent contract. The package has no dependency on Host sources. Its invocation context requires Host-owned runtime grants for the executable, workspace, credentials, process and history authorization.

This is local candidate source. Install it only for isolated integration until Host ports, legacy routing and live CLI acceptance have been completed. The candidate is not registered for public release.

Run `npm test` for protocol fixtures and `npm pack` for the local archive.
