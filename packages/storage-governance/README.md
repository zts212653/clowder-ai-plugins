# 存储空间治理

[English guide](README.en.md)

在 Clowder AI 中按磁盘、会话和类别查看文件占用。启用插件后，从左侧打开「存储空间治理」并开始扫描。可按卷、会话和类别筛选，通过路径搜索、翻页、打开文件详情。选择「工作树」时先看登记的 Git 工作树目录及其总占用，再打开某个目录查看逐文件占用。嵌套的已登记工作树单独统计。

## 扫描范围

需要包含 [Host PR #2065](https://github.com/zts212653/clowder-ai/pull/2065) 的版本。Host 从当前所有者的会话目录、附件引用、已登记的工位和作品存储取得来源，并纳入可识别的 Codex、Claude、DeepSeek Harness 原生目录及已知临时目录。旧归档、其他原生客户端的独立数据目录、未登记的导出及会话无法追溯的项目文件需要额外来源。扫描结果会列出无法访问的记录和无法按会话归属的共享数据。

看「磁盘占用」了解文件占了多少硬盘空间。它来自文件系统的分配空间。稀疏或压缩文件的占用可能小于系统显示的「文件大小」。同卷硬链接保留所有路径，只计一次体积。扫描会跳过符号链接、目录联接和跨设备挂载。读取不到的空间数据标为未知。文件占用可能随运行中的进程变化，扫描结果用于盘点。

## 本地安装

从「设置 → 插件集成」上传构建出的插件归档，安装后启用。
