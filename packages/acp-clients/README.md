# ACP 客户端目录

本插件把本机支持 ACP 的 client 保存成命名配置，项目成员选择配置后即可使用。
需要支持 `configurationKey` 客户端目录和持久成员绑定的 Clowder AI Host（基于 PR #1665 的本地扩展）。
只有原始 #1665、尚未包含配置界面的 Host 不能消费本包。

1. 在设置 → 插件中安装本包。
2. 在配置中添加 dsh、Claude Code、pi 预设或自定义 client。
3. 填写命令或可执行文件绝对路径；参数每行一个。命令路径包含空格时直接填写，不加外层引号。
   Node 脚本使用 `node` 为命令，脚本的绝对路径作为第一个参数。
4. 保存并启用插件。在「成员与运行时」的「使用工具」中选择这里配置的 client 并保存。
   旧版成员编辑器可先选择通用 ACP，再选择插件 client。
5. 发消息验证。已激活的配置不代表该客户端已登录、服务可达或模型有额度；实际调用结果为准。

预设只提供参数范例，不安装 client 或启动外部进程：

| client | ACP 入口 | 说明 |
| --- | --- | --- |
| dsh | `dsh --profile acp` | 需要本机已有可用 ACP profile |
| Claude Code | `claude-agent-acp` | 需要单独安装的 ACP 桥，普通 `claude` 命令不是 ACP stdio 入口 |
| pi | `clowder-pi-acp` | 本仓 `@clowder-ai/pi-acp` 桥 + 本机 Pi 1.3+；原 pi-acp 0.0.34 不透传 MCP |

不同机器请修改路径。固定 ID 是成员的绑定坐标，绑定后重命名 ID 相当于移除旧 client；显示名称可以随时改。
最多 32 个 client。参数保持数组边界，不经过 shell 字符串拼接。不要把密钥放入命令或参数。
认证、原生设置和会话由 client 管理；本插件不收集或复制它们。

成员引用形如 `plugin:official.acp-clients/dsh`，不会复制启动配置。
停用插件后绑定的成员不可用，重新启用后恢复。修改启动配置会释放旧连接，需重新建立会话；
原生续接能力由实际 client 提供。卸载不删除用户原生历史或配置。

## MCP 和角色协作

在成员的「高级接入」中勾选 MCP 并保存；在「设置 → MCP 管理」确认 Clowder 协作服务已启用且允许该角色。
Host 自动提供当前角色、聊天、工作目录和回调凭证，无需复制 token，也无需手工编写 Clowder MCP 配置。
客户端自身仍须支持 ACP 的 MCP 服务器参数；自定义 client 不会因为配置在本插件中就自动增加协议能力。

pi 用户先安装本仓桥包：`npm install -g <本地路径>/clowder-ai-pi-acp-0.1.0-beta.1.tgz`。
如果 pi 不在 Clowder 的 PATH 中，设置启动环境的 `PI_ACP_PI_COMMAND` 为实际 pi 入口，例如 Windows 的 `pi.cmd`。
不要在原生 pi 的 mcp.json 再添加同名 Clowder 服务器；会话内自动注册会带上最新凭证。

日常使用：给项目选择这些角色，在聊天中用 `@角色名` 派活；角色可读取聊天、发送协作消息并唤醒其他角色。
用户看到统一的聊天、工具轨迹、收件与回复状态，不需要切换到客户端终端。首次启动可能较慢，等待实际回复才算连接成功。
模型留空会跟随客户端设置；需要固定模型时，在成员模型栏填写该客户端支持的模型 ID。

本包仅包含声明数据，不包含可执行插件、安装脚本或 Host 依赖。pi 的执行桥是单独的 CLI 包。

## Windows 引导目录与失败恢复

包含本轮目录修复的 Host PR #1677 在每个 client 下提供「引导目录」和「检查引导目录」。默认留空自动选择；点击检查后，Host 会显示实际合格路径。
可点击「使用此目录」并保存，或填写另一个绝对路径再检查。父目录必须已存在且安全，最后一级专用目录可由 Host 创建。
该目录用于进程启动隔离，项目工作目录仍由 ACP 会话传入。检查不会启动客户端或修改已有目录权限；成功不代表登录、模型或 MCP 已验证。

配置数据中的可选字段为 `bootstrapRoot`；不填写时省略该字段。自定义 client 始终保留完整检查，不能配置跳过校验或可信 SID。
若 Temp、ProgramData 及所有数据卷均不合格，需要管理员提供祖先链同样安全的专用本地 NTFS 位置；在不可信卷里新建普通文件夹不能解决问题。
不要为使用插件而接管系统盘 owner。修复实际启动条件后再次发送消息即可重试，不必为清除失败缓存重启 Host。
当前为未发布的本地候选包；在插件页「从本地目录安装」选择解压后包含 manifest.json 的目录。
