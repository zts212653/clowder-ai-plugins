# 和猫下象棋

简体中文 · [English](README.en.md)

在你选的对话里，和那只猫下一盘中国象棋。你在棋盘上预选、确认；猫读取当前候选，亲自选棋，再把应招落回同一张棋盘。

## 开始一盘

1. 在插件管理器中，从本地目录或归档安装并启用本包。需要包含 F202 C1 模块与原生工具调用接口的宿主。启用允许插件读取对话、发送消息；对弈操作由本包核对开局时选择的对话和猫。
2. 在想下棋的对话中，请你选的猫“开一盘象棋”。猫调用 `xiangqi_open_game` 后，会给你棋盘链接。
3. 打开链接，点“打开本地棋盘”，再点击己方棋子和落点，查看预选，点“确认落子并发送”。选中和预选都不会提前落子。
4. 等这只猫亲自应招。棋盘自动更新，可以继续下一回合，也可以撤回一步或悔一回合。

再次请同一对话的同一只猫打开棋盘，会继续未结束的那盘。要打开指定旧盘，让猫向打开工具传入原棋局编号即可。另一个对话或另一只猫会得到自己的棋盘，不共享提交权。猫给出的入口需使用你的宿主登录会话打开；点按钮后显示的私人棋盘地址不要转发，它不会提供给猫。入口页需在十分钟内完成首次打开，之后刷新可以继续；链接过期或插件重启后，请从原对话重新打开。

棋盘使用每盘独立的 `.localhost` 本机地址，避免接收宿主的登录 Cookie；已用 Chromium 验证，不需要改本机 DNS 配置。远程浏览器和其他设备不能使用这个本机链接。当前默认人执红先行；本版没有联网匹配、自动代下、自动认输或多盘回放界面。

## 掉线与保存

落子先写入持久棋谱，再通知猫。通知中断时，页面说明“棋已保存”，可以重试；同一次通知只产生一条消息，恢复不会再下一遍。候选过期或棋盘已变化时，猫必须重新读取。

正常关闭和重启后，插件保留棋局并核验原对话、棋搭子与权限，再恢复未送达通知。明确停用会关闭棋盘并撤销旧会话及待办；重新启用后，由你在原对话请求继续。卸载默认保留用户棋谱。本包不自动导入以前的私人棋局，不要求配置用户目录或私人消息地址。

## 单独分析局面

`xiangqi_legal_moves(fen)` 查询合法走法、将军与终局。`xiangqi_analyze_position(fen, timeMs?, maxDepth?)` 返回有预算限制的候选、深度和主要变化。它们不打开对局，也不会自动落子。

对弈工具 `xiangqi_read_game` 和 `xiangqi_play_move` 只接受棋局、版本和棋步；身份由宿主认证的调用提供。搜索在插件自己的进程中运行。棋盘只持有该盘的访问凭据，不接收宿主令牌；完整棋谱保存在安装实例的数据目录中，通知只发回原对话。

当前源码版本为 `0.1.0-alpha.3`，消费公开 SDK `0.3.0-beta.1` / Contract `0.3.0`；源码版本不等于已经发布或加入官方安装目录。具体测试与宿主验收见 PR，安装请使用其交付的确切归档。

仓内开发命令：`pnpm --filter @clowder-ai/xiangqi test`、`test:browser`、`lint`、`build`。启用动作才启动棋桌进程；发现或安装不会自行开局。
