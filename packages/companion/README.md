# 猫猫球

简体中文 · [English](README.en.md)

在桌面上与你的猫语音或文字交流，查看共同历史，并按需共享屏幕。猫猫球是置顶、透明、无边框的小窗口；需要兼容的桌面宿主。

## 开始使用

1. 安装并启用 `@clowder-ai/companion`，通过 Clowder AI 的“聊聊”入口打开猫猫球。
2. 点击猫打开语音或文字控制；右键查看历史、屏幕共享、家园、声音和隐藏选项。拖动猫移动窗口，Escape 收起面板而不结束对话或清空草稿。
3. 只有明确点击“语音聊”才开启麦克风；通话时可通过始终可见的标记一键结束。屏幕共享另有明确的选择与结束操作。

兼容宿主提供“只听”时，可以接收同一对话的音频而不申请麦克风。较旧宿主不显示这个入口。语音关闭时仍可独立输入文字。

## 历史与草稿

小窗显示有限数量的近期历史，“完整聊天”打开对应的正式对话。每条消息沿用宿主提供的真实作者与当时角色信息，不用当前选择的猫替换历史身份。

草稿由宿主持久保存。发送结果不明时先读回状态，不自动重发；明确重试沿用原消息身份和内容。切换正式对话后，旧的未确认输入保留为已失效文字，不会自动发进新对话。历史加载进度、回复处理状态与正文是否完整分别展示。

## 桌面行为与隐私

需要桌面桥接版本 1.8.0（插件契约 0.3.3-candidate.2）；更早的宿主会在安装前拒绝这个包，不会只打开一半。宿主控制窗口位置、拖动与透明区域点击，负责媒体授权和采集；插件不接收原始媒体流或提供方会话凭据。隐藏窗口会释放媒体资源，重新通过“聊聊”打开。

桥接 1.7 增加“桌面猫带来”：宿主可以把猫做好的东西交给桌面猫递到你面前，一次一件或回来时一组。小窗只收到标题、一句话、来源对话名和不透明引用，缩略图和送来那只猫的头像都由宿主以内联图片字节提供；打开、添加、忽略和倒计时结束都交回宿主处理。倒计时沿用回复气泡：指着、聚焦或滚动时暂停，点圆圈留住。只有宿主确认已保存时，猫旁才会短暂显示“已保存到对话”。

桥接 1.8 增加“活猫身体”（livingBody）：包里多一个 `renderer/body.html`，在猫旁设置的“外观”里选“宪宪（活猫）”（只有这条契约线上的包才提供这个选项）后，小窗不再画自己的猫，宿主为它开一扇铺满主显示器工作区的透明窗，猫在里面沿工作区底边活动；菜单、聊天、通话、待拍板和桌面投递仍在原来的小窗里，屏幕上始终只有一只猫。身体页只能发身体和场景命令：报告可点区域（变了才报，另有每 500 毫秒一次、与重画无关的续租，1.5 秒没续桌面就恢复可点）、报告猫身体的位置、右键打开原菜单（宿主收到后给小窗发 view-open 事件，小窗在猫旁打开自己的菜单）、读取和报告场景。场景由宿主代存、不设过期；读不到存档时照常演但不写，按 1 秒到 30 秒退避重读。身体页跑的就是卡片里的引擎（宪宪和纸团 v30）：纸团、爬墙上天花板、草稿、理毛、发呆、摸摸、揉帽子、闻手、手快扑手、躲纸箱。按在空白处仍是点你自己的桌面，只有按在纸团上才拿起纸团。他默认站高约 150 像素；宿主的 body-area 事件带上由“大小”设置换算的站高（`standHeight`，60–480 像素）后按它画，但不会大到让可点区域超出宿主的上限。图集是包里自带的 0.6 倍素材（解码后约 112MB；爬墙那张等纸团粘上天花板才加载）；画面变了才重画，窗口隐藏时他的时钟停走。关掉再打开，他直接回到原样：姿态和位置、纸团、草稿纸、歪着的帽子、没做完的草稿或理毛；离线期间的事不补演，也不计时。

应用协助默认关闭，确认提示只打开普通菜单，不会自动授权屏幕或通话。角色动画受宿主当前事实驱动；拖动时暂停自主移动，减少动态效果设置保留静态姿态。自动玩耍受空闲和冷却时间约束，默认扑跃需要明确操作。

宿主管理安装、调用上下文和启停。英文文档是独立文件，互链不代表页面已支持自动语言切换。
