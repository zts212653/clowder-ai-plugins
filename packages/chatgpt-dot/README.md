# Dot 云端对话插件

[English guide](README.en.md)

Dot 把已配对的 ChatGPT 云端对话接入 Clowder AI。安装实例可作为独立目标接收召唤；云端先读取原消息，再把文字回复和原始 PNG 发回同一对话。它也能向已加入对话的家猫提问，并接收这些提问的回复。

维护者：Clowder AI 插件团队。当前版本为本地候选，需要支持可寻址插件声明的配套 Host；未发布到官方目录。组件与打包验证不能代替真实 ChatGPT 账号的连接验收。

## 安装与连接

在插件管理器选择本地插件目录或作者提供的完整归档。归档携带实际运行依赖，不需要另装 SDK。当前完整归档已在 macOS Apple Silicon 验证；其他平台需从源码构建对应依赖，尚未验收。安装后打开「Dot 连接」，选择「准备连接」，先启用插件，再按返回的配对说明在目标云端对话订阅召唤事件。实际可用的安装、设置和旧连接导入入口由配套 Host 提供。

配对固定到所选云端回调地址。选择「重新配对」会换掉配对标识，旧召唤将失效；「断开连接」撤销当前口令。外部连接预设口令可以留空，配对流程会生成口令，旧连接迁移会保留原口令，无需重填。请勿把口令贴到公共对话或诊断日志。

代理为可选项，仅支持本机 HTTP CONNECT 代理；默认直接使用经过地址校验和 DNS 固定的 HTTPS 回调。别名、图标与安装实例标识由 Host 管理。

## 使用与恢复

在对话中选择 Dot 并发送消息。投递确认表示云端收到了召唤；模型回复会作为另一条普通插件消息出现。每个召唤都必须先读原消息；改用其他对话或其他配对的事件标识不会获得回复权限。新原图经普通附件流进入 Host 的消息与媒体存储，可在消息里查看。

连接检查同时展示配对和最近读取、回复、图片证据。启用后可「发起往返测试」，在云端回复原消息中的随机校验码，再执行连接测试确认。仅订阅成功或 HTTP 成功不表示模型已经回复。

停用会撤销运行实例并中止网络请求；重新启用会从持久记录恢复配对和仅用于既有提问的线程订阅。旧客户端在插件停用时不可继续调用。配置、配对、请求记录和原图在停用及卸载时保留；卸载不会删除历史消息。

## 升级与旧数据

旧连接的口令、配对、订阅、请求和回复标识保持不变，仅将记录归属显式映射到新安装实例。导入校验安装主人、图片摘要和字节大小，返回可重试的批次回执；原文件不删除。Host 在切换前复核旧授权；后续导入可将同一连接加强为撤销状态，重试不会恢复口令或覆盖首次撤销时间。

历史图片使用的旧地址由配套 Host 保留兼容读取。导入和兼容路由需要与 Host 一起验收；本包不会自行读取其他项目目录或改写历史消息。

## 开发

从插件仓根目录安装依赖，先构建 Contract 和 SDK，再运行本包的 typecheck、test 和 build。运行入口是 dist/plugin-entrypoint.js。Host 通过清单声明的非 UI action dot.import，在启用前经 owner-operation 边界导入；./migration 导出提供批次 schema。批次接受明确的记录和原图字节，不接受服务端文件路径。

测试覆盖配对、签名召唤、先读后回复、图片流、重试、停用中止、恢复和旧数据导入。最终账号连接、设置页面及完整往返仍须在隔离 Host 中验证。
