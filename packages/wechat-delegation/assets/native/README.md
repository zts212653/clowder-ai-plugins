# Clowder WeChat Link — internal integration artifact

This directory now bundles our restricted `clowder-wechat-link`, built from the source in `packages/wechat-delegation/native/`. It replaces the former Agent WeChat HTTP daemon executable. The package is still an internal development candidate: `accountServiceReady=false`, full authentication/message-baseline/repair journeys and real-account acceptance remain open. Do not install this working version over the user's running plugin.

`manifest.json` binds the compressed and executable bytes, Cargo lockfile, protocol source manifest and patch. The source commit refers to the native source, not a claim that the complete plugin was already accepted at that commit. The fixed MIT protocol source is `thisnick/agent-wechat@ed976d78c1e1cc2a49ad17d1e2c0da023bbb5c8e`; all 26 reconstructed protocol files are recorded by `native/UPSTREAM.json` and `native/protocol.patch`. Application code, Vault, Keychain shim, stdio service and Host adapter are our implementation. `current-directory.patch` is a retained historical source reference for the retired daemon; it is not applied to this binary.

The current artifact was built with Rust/Cargo 1.93.1 for aarch64-apple-darwin, Apple SDK 26.5 and explicit `MACOSX_DEPLOYMENT_TARGET=26.5`. The Mach-O header records minimum macOS 26.5; it has only been tested on that host. No support for earlier macOS, Intel or Linux is claimed. The signature is the linker's ad-hoc signature, with no TeamIdentifier or notarization; distribution signing and upgrade reauthorization are still pending. `otool -L` shows only system Security/CoreFoundation, libiconv and libSystem. OpenSSL 3.6.3 is statically vendored from the locked dependency, confirmed by the release build output. This is an inventory claim, not a zero-vulnerability assessment.

Rebuild from the native source with the manifest's build command. Compress the resulting executable with gzip, replace the bundle and recompute both hashes. Compiler, SDK and absolute build paths may change executable bytes; byte-for-byte reproducibility across machines is not claimed. Any native source change requires rebuilding and rerunning the physical artifact checks before a final candidate is published.

The Supervisor starts only on an authenticated owner preparation, with exact byte verification, private stdin/stdout, no inherited owner environment and an isolated `link-vault`. It has no HTTP token/listener or legacy profile migration. Native startup clears its environment again. Normal tests use a synthetic executable/store; the actual bundled executable is exercised only in its no-argument offline mode, which does not open a default Keychain. Real Keychain tests use separate synthetic Keychains. This is not real login, message delivery or installed-product acceptance.

`dependency-licenses.json` lists the locked reachable runtime and build dependencies (including build-only tools, not a claim they are linked). `licenses/` copies their supplied license/notice files and the Rust standard-library copyright bundle. `LICENSE-Agent-WeChat` and `LICENSE-CITIZENLAB` preserve the protocol and test-vector attribution. No old audio/media/call/SQL engine is bundled in this executable. Formal publication remains gated by exact final bytes, independent review and the owner's explicit release authority.
