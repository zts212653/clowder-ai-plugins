# 微信代聊（开发候选）

简体中文 · [English](README.en.md)

以插件形式，让指定猫在本人明确授权的微信好友或普通群中主动发起、持续接话，并提供会话级“我来聊”和全局“暂停全部代聊”。普通授权内的消息不要求本人逐条批准。

本包使用第三方 Agent WeChat 的个人号 native HTTP API，**不使用 iLink Bot 或桌面 OCR 代替好友/群托管**。开发候选包含真实 API 适配与产品入口；隔离模拟测试不证明真实账号兼容、账号安全或真实微信收发已验收。

当前包为 `private` 开发候选，可从校验后的本地归档安装，避免在真实旅程验证及独立审查前意外发布到 npm 或正式目录。这不改变插件运行形态；正式分发须另走仓库的目录与发布计划。

## 使用路径

1. 在相容 Clowder AI 宿主安装此插件候选并启用，关闭介绍页，点击最左侧导航栏靠下的“微信代聊”对话气泡图标打开控制台。介绍页仅提供说明与启停管理；账号连接、授权与接管集中在控制台。启用本身不会启动第三方进程或代聊。
2. 阅读第三方组件与数据同步说明，点击“准备账号连接组件”。插件下载固定版本并校验 SHA-256，启动专属进程；无须复制令牌、编辑配置或执行终端命令。
3. 用手机微信扫描本次真实二维码并确认。已有专属客户端保存登录时可能恢复连接和同步；猫仍没有任何会话处理权。账号核验后显示实际微信身份。
4. 从平台真实列表选择具体好友或群，从宿主成员列表选择猫，设置人设、聊天目标、是否允许主动发起及自动接话，核对实际模型服务后明确开启。
5. 点击“立即主动开口”，或另行开启持续主动策略。持续策略按明确时区、时段、间隔和每日次数执行，对方未回时不继续追问。群授权不扩展到群成员私聊。
6. 随时点击该会话的“我来聊”或顶部“暂停全部代聊”。本地后续代聊先停止；已经交给组件但取消未确认的消息仍可能发出，会逐条显示。只有本人明确交回才能恢复。

选定提醒对话后，本人在那个可信 Clowder 对话中单独说“我来聊”或 `/takeover`，也会停止绑定在那里的代聊；说“暂停全部代聊”或 `/pause-all` 则全局停止。仅接受宿主回读的真人原消息，不接受微信外部联系人或展示名称冒充。此入口依赖宿主提供可信作者事实，按钮接管始终保留。

“暂未在微信看到”不能证明消息没有发出。未知结果只查询原发送键，不自动重发。本人核对实际会话与全文，确认已经发出后可记录观察结果；这与平台回执独立。

## 宿主与账号组件

- 需要支持标准 builtin 插件、owner HTTP 面板、Host storage CAS，以及受限 `memberSessions` 的宿主。受限执行缺失时明确不可用，不回退到全权限家庭猫。
- 模型会话只使用本次批准的猫及模型账号，`memory=[]`，插件 MCP 不暴露任何工具、资源或提示。模型只能返回结构化文字建议，不能自行修改授权、收件人、支付、文件、命令或外链权限。
- 当前固定的 native 组件为 `thisnick/agent-wechat` 的 `v2.4.1`（MIT），支持已登记校验的 macOS ARM64、Linux ARM64/x64 制品；其他平台显示未就绪。固定来源与摘要在 `src/native-supervisor.mjs`，不会追随 `latest`。
- 组件仅在本人从控制台准备时启动。其数据目录是宿主 `dataPath/native-profile`，启动配置目录为 `dataPath/native-config`；两者均由插件独立持有，不继承家庭 HOME 或接管官方桌面微信 profile。凭据通过私有 stdin 管道传给组件，不进入模型、聊天、URL、命令行参数或日志。
- 客户端可能同步所选范围以外的微信数据到本机。插件只对已授权的账号与稳定会话 ID 取正文、送模型和外发；列表只向本人呈现必要元数据。
- 后端 HTTP 只连接本次拥有的 loopback 服务；每次外发前核对 daemon serverId、实际微信身份及当前授权版本。请求禁止重定向和超大响应。

## 持久状态与恢复

账号客户端数据、会话设置、代聊策略和每次发送记录保留在宿主专属持久空间，不设自动删除 TTL。用户主动选择的执行到期只限制后续执行。

停用、进程退出、配置变化和宿主重启不会恢复旧许可。重启保留配置与历史，暂停所有代聊；在途结果仍需核对。重新授权使用新的策略版本及受限成员代次，旧进程、旧猫、迟到草稿和旧批准不能继续发送。

资金、验证码、密码、账号安全或对方找本人等明确边界会暂停并交给本人。文字规则和模型不能证明覆盖所有诈骗或语义风险；第一版只发送文字，不执行支付、附件和链接行为。可指定一个实际 Clowder 对话接收需要本人处理的提醒。

## 开发验证

```sh
node --test test/*.test.mjs
npm run build
```

`test/native-client.test.mjs` 调用真实本机 HTTP 测试服务；`test/native-supervisor.test.mjs` 启动隔离的合成测试程序，验证摘要、私有令牌传递、进程身份与停止，不运行供应商二进制。其余测试验证接管竞态、权限与群/好友隔离、重启及未知结果不重发。打包测试在空白离线 consumer 导入并启动最终制品。

浏览器旅程从 `scripts/preview.mjs` 的隔离模拟环境验证发布物中的真实控制台；它不连接真实账号、不调用真实模型、不向微信外发。模拟测试、供应商 native 制品的实际运行、本人扫码以及好友/群真实实收与接管验证分别记证据。
