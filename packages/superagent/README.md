# 常驻助手（Superagent）

[English guide](README.en.md)

安装到 Clowder AI 后，会话列表顶部出现“我的助手”。先打开插件的启用开关，再在同一设置页填写并保存允许处理的工作，分别选择助手 Agent、执行 Agent 和监听会话，最后确认开始跟进。

助手 Agent 只选一位，负责理解委托、跟进进展和派工；执行 Agent 可以选多位，负责具体任务，同一成员也可以兼任助手。监听会话单独选择，决定它能从哪里接工作。这些选择会即时保存；确认开始跟进前，不会监听所选会话或派发任务。

它根据所选成员的语义判断区分新委托、旧工作反馈、背景和未定想法；独立工作使用各自执行线程及 canonical Task。必要决定和结果回到原会话，主对话保留同一事项的跟进。

暂停停止新接单与派发，已有工作仍可回报结果。停用撤销插件运行和订阅，保留会话、工作与历史。正常重启重建已选订阅并续接待处理操作。本机 Host 关闭时无法继续执行。

该 alpha 版本需要支持 `thread-sidebar.top` 通用入口的 Host。仅安装不表示已经开始监听；设置完成后才会调用所选成员。新工作不得越过填写的责任范围，发布、数据删除等重要动作仍需原有授权。

通过设置中的插件集成安装目录提供的精确版本。安装需要网络以取得发布者锁文件中的依赖，无须手动安装 SDK 或 Contract。目录上架不表示所有旧版 Host 都已兼容；若 Host 不支持顶部入口或相关设置操作，需要先更新 Host。

同一 `official.superagent` 的升级保留助手名称、工作范围、已选成员、会话和持久工作记录；本版不改变存储格式。暂停不取消已有订阅，已有工作仍可回报；停用才撤销运行和订阅。插件通过 Host 读取选定会话并调用所选成员，没有独立的外部账号授权。所选成员的供应商可能会处理这些消息并消耗额度。

由 Clowder AI 维护，问题与功能建议提交到[插件仓库](https://github.com/zts212653/clowder-ai-plugins/issues)。当前为正式目录分发的预发布版本，尚不承诺真实模型能可靠识别所有异常或自动完成跨成员纠偏。

开发验证：`npm run typecheck`、`npm test`、`npm run build`。编排单元测试中的模型判断为脚本输入；真实模型、完整 Host 与跨平台验收另行记录，不能将单元测试当作产品验收。

运行依赖固定为已发布的 SDK、Contract 和 Zod，安装闭包由 `npm-shrinkwrap.json` 记录。发布使用仓库贡献指南的固定工具链与规范打包命令；候选发布、目录激活和真实安装验收分别核对。
