# 常驻助手（Superagent）

[English guide](README.en.md)

安装到 Clowder AI 后，会话列表顶部出现“我的助手”。先打开插件的启用开关，再在同一设置页填写并保存允许处理的工作，分别选择助手 Agent、执行 Agent 和监听会话，最后确认开始跟进。

助手 Agent 只选一位，负责理解委托、跟进进展和派工；执行 Agent 可以选多位，负责具体任务，同一成员也可以兼任助手。成员选择即时保存。监听会话通过“选择监听会话”打开原生窗口，沿用会话列表的分组、置顶与顺序；勾选不会重排，保存后才更新范围，取消不修改。搜索隐藏的已选会话仍会保留。确认开始跟进前，不会监听所选会话或派发任务。

助手主对话会显示首次连接时的状态说明，这条说明不调用模型。打开入口只进入对话，不会扫描旧消息或重新派工。跨会话事件、工具指令及协调成员的过程回复进入插件创建的“内部协调”会话，不再逐条出现在“我的助手”；无需用户维护这个协调会话，也无需把它选入监听范围。已有负责人接住的事项登记后保持安静。若助手本轮结束却漏记判断，主对话只显示带原会话标题、链接和具体重试入口的失败通知；事件仍保留，不会自动重复消耗额度。升级前仍在主对话运行的调用沿原消息完成，历史消息不删除。

开始跟进后，助手会只读盘点已选会话中的现有工作，并约每分钟检查一次完成与阻塞变化。首次盘点会补报已完成和受阻的任务；之后状态未变不重复发送，重启也不会重报。每次合成一条摘要，最多列三项并保留原会话入口；还有变化时明确给出剩余数量，可询问“展开进展”。普通进行中状态、问候和泛泛的催问不主动发送。已有任务保留原负责人；有正式验收记录时以该记录为准，模型回复结束不代表任务完成。未登记任务的会话成果仍需成员结合原文判断，不承诺自动识别所有完成情况。

一次判断失败只保留该事件等待明确重试，不阻断其他会话的新事件；现有任务状态盘点不调用模型。暂停时停止新的盘点，停用与重启保留去重记录。

普通成员汇报、审查交接和系统提醒不再逐条唤醒助手；它们的任务状态由只读盘点跟进。结构化的成员失败仍会交给助手分析建议，插件已有工作也保留原来的反馈链。只有当前用户的消息才能作为新建工作的来源，成员汇报不能授权新立项；升级前未执行的非用户派工也会被拒绝并保留审计。没有任务记录的成果需要在用户询问时结合原会话判断，不能只凭模型回复结束自动宣布完成。

插件工作线程里，执行成员的普通过程消息不会再唤醒协调成员，同一成员兼任两种角色时也不会互相回灌。正式结果仍通过报告交回；真实失败仍保留原失败报告链。若成员结束却漏交结果，只发一次带来源的失败通知，不用另一个模型回合重新解释这次结束。

主会话里的结果、问题和失败通知写明事项、来源会话标题与链接、已有工作目标作为背景，以及具体的下一步。待验收结果与已经完成的记录分开表述，不把每条消息都变成需要用户作决定。长工作结果显示明确标注的原文首段节选和全文入口，完整报告仍在原会话；从主会话交办的工作，其完整长报告保存在对应工作线程。

它根据所选成员的语义判断区分新委托、旧工作反馈、背景和未定想法；独立工作使用各自执行线程及 canonical Task。必要决定和结果回到原会话，主对话保留同一事项的跟进。

暂停停止新接单与派发，已有工作仍可回报结果。停用撤销插件运行和订阅，保留会话、工作与历史。正常重启重建已选订阅并续接待处理操作。本机 Host 关闭时无法继续执行。

该 alpha 版本需要支持 `thread-sidebar.top` 通用入口及 `thread-picker` 原生选择器的 Host；只更新插件不会给旧 Host 增加选择器。仅安装不表示已经开始监听；设置完成后才会调用所选成员。新工作不得越过填写的责任范围，发布、数据删除等重要动作仍需原有授权。

当前通过设置中的插件集成安装本地构建的精确 `.tgz` 归档。公开 npm 分发与官方目录准入由 [#214](https://github.com/zts212653/clowder-ai-plugins/issues/214) 跟进，配套 Host 和维护者准入决定完成前暂缓发布。安装需要网络以取得发布者锁文件中的依赖，无须手动安装 SDK 或 Contract；若 Host 不支持顶部入口或相关设置操作，需要先更新 Host。

同一 `official.superagent` 的升级保留助手名称、工作范围、已选成员、会话和持久工作记录；偏好和工作格式不变，运行记录新增可续接的协调会话坐标。协调会话在重启后复用，并从可监听目录排除。暂停不取消已有订阅，已有工作仍可回报；停用才撤销运行和订阅。插件通过 Host 读取选定会话并调用所选成员，没有独立的外部账号授权。所选成员的供应商可能会处理这些消息并消耗额度。

问题与功能建议提交到[插件仓库](https://github.com/zts212653/clowder-ai-plugins/issues)。当前为本地归档试用版本，尚未获得官方目录准入，也不承诺真实模型能可靠识别所有异常或自动完成跨成员纠偏。

开发验证：`npm run typecheck`、`npm test`、`npm run build`。编排单元测试中的模型判断为脚本输入；真实模型、完整 Host 与跨平台验收另行记录，不能将单元测试当作产品验收。

运行依赖固定为已发布的 SDK、Contract 和 Zod，安装闭包由 `npm-shrinkwrap.json` 记录。发布使用仓库贡献指南的固定工具链与规范打包命令；候选发布、目录激活和真实安装验收分别核对。
