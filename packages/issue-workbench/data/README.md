# Initial classification data

`initial-classification.v0.json` is the versioned public result dataset shipped
with this plugin. It was moved unchanged from the design evidence directory when
the workbench gained its classification overview. Plans reference it, not vice versa.

The 12 proposals were generated by GPT-6-astra from selected public issue titles
and body excerpts on 2026-10-14. The file preserves the taxonomy, exact public source
identity, observed update time, body hash, excerpt, model and sampling limitations.
No private issues, credentials or production store are included. `humanAcceptance`
remains null: explicit local adoption is saved in the owner's work record, not back
into this immutable baseline. No confidence, training or accuracy result is claimed.

The example Host maps stable taxonomy IDs to readable names and passes results
through the source grant/identity filter. The frontend reads authorized results
from the Host; the JSON is not embedded in the browser bundle.
