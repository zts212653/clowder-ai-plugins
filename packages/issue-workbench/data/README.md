Provenance: current `gh issue list --state all --limit 3000` facts, not the old
October 14 snapshot. GPT-6-astra reviewed each unbound title, consulting selected
ambiguous bodies. This pass does not claim complete body/comment reading, trained
weights, embedding/clustering, measured accuracy or a continuously running classifier.
Type and environment are explicit source/title hints; symptom remains empty.
Bare `feature` and title mentions do not bind a Feature.

`catalog.issues` preserves the observed identity, title, status, labels, updated
time and body SHA-256. The compact sorted-key JSON hash contract is recorded in
`catalog.snapshotHashContract`. The package includes no full issue bodies/comments.
The suggestions and Feature-bound set partition the observed corpus; `test:data`
checks identity, coverage, evidence, taxonomy, counts and unaccepted status.
Live label changes are resolved by the Host; newly fetched unbound issues remain
visibly unclassified until a later batch. No remote labels are changed.

## Historical seed

`initial-classification.v0.json` is the historical public result dataset shipped
with this plugin. It was moved unchanged from the design evidence directory when
the workbench gained its classification overview. Plans reference it, not vice versa.

The 12 proposals were generated by GPT-6-astra from selected public issue titles
and body excerpts on 2026-10-14. The file preserves the taxonomy, exact public source
identity, observed update time, body hash, excerpt, model and sampling limitations.
No private issues, credentials or production store are included. `humanAcceptance`
remains null: explicit local adoption is saved in the owner's work record, not back
into this immutable baseline. No confidence, training or accuracy result is claimed.

The example Host maps stable taxonomy IDs to readable names and passes results
through the source grant/identity filter. The frontend reads authorized results
from the Host; the JSON is not embedded in the browser bundle.
