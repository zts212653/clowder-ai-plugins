# DSH Workbench · 系统底包

这是一个用于 Clowder AI 的界面主题，基于系统 `default` 主题，提供 DSH 风格的会话侧栏、消息布局和工作区。主题 ID 为 `dsh-system`。

## 安装或更新

1. 下载 [dsh-system-0.2.26.theme.zip](dsh-system-0.2.26.theme.zip)。
2. 在 Clowder AI 打开「设置 → 主题 → 导入」，选择 ZIP，然后启用「DSH Workbench · 系统底包」。

导入会更新同一个主题包，基于它保存的自定义字号可以继续使用。当前窗口已启用此包时，导入会重新载入窗口，请先保存未提交的输入。

## 0.2.26

- 侧栏在独立一行显示最多四枚标签。会话标题开头的 Issue 和 PR 编号也可在该行查看，原标题继续用于搜索和重命名。
- 侧栏支持为当前会话行内添加或移除标签。编辑时只显示一组标签，切换会话会退出编辑并丢弃未提交的输入。
- 侧栏拖拽区和收起按钮之间留出间距。1440 和 1100 像素宽的验收窗口实测均为 18px。

## 0.2.21

- 会话中的表格容器与正文对齐。列放不下时可以在表格内横向滚动，宽表格支持键盘滚动。

## 0.2.20

- 侧栏「新对话」在浅色和深色下都提供悬停底色及键盘焦点框，和下方快捷入口间隔 12px。

## 0.2.19

- 选中或带副行的会话，右侧更多／删除／置顶、时间和左侧运行／未读状态沿整条会话行垂直居中。
- 支持鼠标和键盘置顶。已在 Clowder AI Windows 桌面及隔离的 390、1100 和 1400 像素宽视口验证此变更。

主题接口版本为 `0.4.0`。0.2.26 在 Host `c2d49547c4ce8343ea6c662df6176a0f2a444d2c` 的隔离环境中，通过 Windows Electron 和 Edge 分别验证标签切换及侧栏拖拽。
