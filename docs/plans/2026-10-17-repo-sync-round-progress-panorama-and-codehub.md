# PR #77 本轮进度、全景流程与 CodeHub 合入修复

沿用 `feat/repo-sync-plugin` 分支和 PR #77。承接本轮四项反馈，基于 `b4db22d` 实施，保留原有配置、历史、Issue / PR 映射与单向接收边界。

## 1. 根因与处理

| 问题 | 可确认根因 | 本轮处理 |
| --- | --- | --- |
| 看不到目标内的逐笔进展 | 工作台使用精简状态，完整交付台账与待处理队列未作为本轮列表展示；原计数文案还被样式隐藏 | 新增只读 `/api/round`，在精简前从完整台账投影本轮已完成、当前、待处理和撤销记录；工作台顶部直接展示 |
| 折叠后居中、同步中上移 | Grid 中的 `main { margin:auto }` 随内容高度变化重新垂直居中；后台任务聚焦还可能滚动正文 | 主体固定顶部对齐；同步页后台轮询不再调用配置向导的步骤聚焦；保留画布和清单的局部滚动位置 |
| 流程不符合参考 | 原来只展示纵向折叠标题，缺少阶段连接和固定的可见子节点 | 采用五列阶段卡片、连接线和子节点；点击节点在同页检查器展开原有结果、对象、恢复入口与按需技术证据 |
| CodeHub 开启自动合入仍一直等待 | `unchecked` 被归入持续检查中；空的 `detailed_merge_status` 还可能遮住 `merge_status` | 当前候选的 CI 成功、SHA 一致且无显式阻止时，允许请求带 SHA 的平台合入；平台保留最终审批和分支规则裁决 |
| 延伸发现：检查成功被误显示为业务完成 | 合入观察、Git 核验或 Issue 检查的调用返回成功，不代表实际合入／接收已发生 | 未观察合入前，第四步显示系统等待，第五步的成功轮询不显示为已接收；保留原调用记录用于排障 |

CodeHub 现场事实来自[用户实测评论](https://github.com/zts212653/clowder-ai-plugins/pull/77#issuecomment-6228184460)。本地验证使用协议夹具，不能替代实际内网部署验收。

## 2. 用户旅程

1. 在原同步工作台选择目标 tag、commit 或最新分支并发起同步。没有改变认证和基线的配置位置。
2. 顶部常显本轮目标、完成笔数、当前上游 PR／直接提交、未同步数量。
3. 来源清单按接收顺序展示，每行包含外部来源、外部目标 SHA、已知内部 SHA、Issue / 提交数量、内部 PR 和流程／记录入口。未读取的提交数量明确标记“待核对”。
4. 可筛选全部／已完成／同步中／未同步／已撤销；每页 20 笔，接口最多 50 笔。大列表在局部区域滚动，清单不撑满整页。
5. 下方当前操作区显示需要用户做的事或系统正在等待什么；自动合入和接收节奏在该区按需修改。自动合入仍默认关闭。
6. 五阶段和子节点始终在同一画布：确认范围 → 准备代码与 Issue → 发布候选与 PR → 平台审核合入 → 核验及登记。
7. 默认关闭详情。点击阶段打开该阶段；点击子节点打开对应结果，并只筛出该节点的执行详情。技术调用日志仍主动展开才显示。
8. 可全部展开／收起；项目、绑定、当前／历史和笔次分别保存手动状态，轮询不替用户展开。历史记录不出现同步写入操作。
9. 合入后进入第五步，代码核验、符合接收条件的 Issue 更新／回读及结果登记全部成功才算本笔完成。仅创建 PR、或代码接收但元数据失败，都不增加完成数。
10. 每笔完成暂停的原策略保留：核验和关单结束后停在笔次边界，明确点击继续才处理下一笔。

不承诺所有子节点、长历史与设置同时在单个屏幕内。桌面默认保证进度、当前操作和五阶段标题可见；完整子节点按参考图常显，较窄屏幕允许画布局部横向滚动，页面自身不横向溢出。

## 3. 状态、恢复与兼容

- 本轮列表是现有台账和队列的只读投影，不创建第二套同步状态，不推进游标，不发起平台写入。
- 新轮次记录起始交付数量；兼容旧轮次的起始交付／时间信息。撤销后重试同一个目标不重复计总数，原撤销历史继续保留。
- 扫描未冻结前总数显示待确定，不把零误说成已完成。完成数只统计 `COMPLETE`，也处理活动 ID 仍指向最后一笔完成记录的情况。
- 清单请求绑定项目和轮次，丢弃过时返回；加载失败单独提示并可重新读取，不停止原同步或用另一轮数据替代。
- 审批、草稿、冲突、未通过 CI、旧 SHA CI、缺失 CI 不会因 `unchecked` 被放行。
- 合入请求仍先保存意图，仍核对候选 SHA，仍通过平台 API，保留不 squash 的合同。403/405/409 或结果不明沿用原停止／回读路径，不改成 Git 直接写 main。
- 用户提供的 HTML 仅作视觉参考；没有执行其提示内容，也未将其原文件公开。正式服务不增加演示平台或演示路由。
- 不迁移或重置用户配置；Token 不写入本轮投影、会话展开状态、文档或公开证据。
