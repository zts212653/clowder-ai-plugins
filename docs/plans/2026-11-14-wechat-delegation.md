# 微信主动代聊插件实施

范围：已确认的微信授权与安全接管设计及其主动代聊要求；开始实现与责任记录保留在共创任务中。

Before：本人逐条读消息、构思和发送，猫只能提供草稿。
After：本人选具体好友/群、猫、话题与频率并明确开启，猫主动发起并接话；本人随时接管，明确交回才恢复。

## 契约与范围

- 新包 `packages/wechat-delegation`，builtin 插件、现有 owner HTTP 面板与设置入口；不改动 iLink/OCR 以冒充个人会话。
- 真实通道适配候选为 agent-wechat native HTTP API v1，固定审读 SHA `1e7dec817ca2ff893b8365b768058b6c0274563d`，MIT。只读克隆不代表采用/安装 native binary；平台兼容、安装来源与真实账号风险仍需验证。
- 账号/会话/策略/运行账本归插件，持久化使用 Host storage CAS，无 TTL。平台身份以服务端事实为准；底层客户端可能同步更广范围，模型只接收明确授权会话。
- 模型调用只使用可选 Host `memberSessions` 受限成员端口及空工具 MCP，memory=[]；缺失时明确未就绪，不回退到全权限家庭猫。
- 同一持久账本的串行提交把接管与发送关口排序；接管先落盘再取消 daemon 待发。已移交但未确认取消的项仍为在途；超时只查原发送，不自动重发。
- 重启/配置变更暂停全部代聊，保留配置、历史和未知结果；本人重新确认后才恢复。
- 全局接管同时更新持久控制版本；正在准备模型授权的新会话也受它约束，不能在暂停后迟到开启。可信 Clowder 原始本人消息可在已选提醒对话中触发同一停止，不接受外部来源冒充。
- 好友与群分别验证。主动发起不依赖新收到回复令牌；固定目标，不遍历群员私聊。第一版对外只发文字，不执行链接、附件、支付、账号操作。

## 实施与验证

1. Node 原生行为测试保护发送前接管、生成中接管、适配器接收后接管、迟到回执、未知结果不重发、切猫与重启暂停、未授权会话不送模型。
2. 实现持久策略与发送账本、native HTTP client、受限成员 runner。网络测试用隔离 loopback fake daemon；与真实微信证据分开。
3. 消费小多子的授权/接管实现规格，落实 plugin.yaml、owner HTTP 面板、配置与精确状态。所有写操作验证 Host owner context 与当前实例；配置内容不承载授权凭据。
4. `node --test packages/wechat-delegation/test/*.test.mjs`；`pnpm --filter @clowder-ai/wechat-delegation build`；从 `npm pack` 发布物在空白 consumer 验入口与依赖闭包。
5. 非作者独立审查后提供候选安装包；真实账号授权、真实好友/群实收与接管验证未完成前不称产品完成。

## 成本与待证据

个人号协议需要独立 native daemon 和账号登录，可能增加进程、磁盘同步、账号兼容风险；因此先核固定 API 与取消语义，再决定受监督 runner 的交付。保持敏感数据与凭据在宿主/客户端，不进入模型。无代聊时不启模型；轮询可取消、无自动付费重试。用户只负责不可推断的账号身份、目标对象和代聊边界，不抄令牌/内部 ID。

已核：固定版本制品的发布方摘要、native API 中的实际账号身份字段，以及当前 Host 源码的受限成员接口。仍待核：供应商制品的实际运行、所安装宿主的实际接口可用性、本人扫码及好友/群实收、daemon 取消的真实竞态边界。测试中的假平台不作真实能力证据。

## Architecture ownership

Architecture cell: `packages/wechat-delegation`，独立 builtin 插件。平台账号进程、稳定身份绑定、授权策略、发送账本、接管与通知由本包负责；Host 保留本人身份、成员执行权限、模型凭据及持久存储的权威。

Map delta: 新增个人微信 native adapter、受监督进程、持久策略/发送协调器和 owner 控制台；不修改 Host 契约或已有 iLink/OCR 包。复用现有 owner HTTP、storage CAS、memberSessions、消息订阅；增加本包的 CI 路径与检查阶段。此外部插件仓没有家内 architecture-map 检查入口，归属在本计划及包目录维护。

Why: 用户需要实际个人号好友与群的主动外发和可中断代聊。独立插件将账号组件及数据留在专属目录；由一个持久顺序决定授权、接管与移交，避免 UI、模型与通道各自持有不一致的许可。
