# 配置后自动同步、人工审核合入

来源：用户要求无 PR 主干提交正常自动纳入；认证在初始配置集中完成；点击同步后自动创建 Issue、候选和 PR，人工只在平台审核合入；合入后自动核验、关单并继续。另需解释和减少额外接收节点，提供提交身份选择，全景流程自动折叠完成步骤。

## 状态与行为

- 无关联 PR 的主干提交不再需要选择，不省略代码，不伪造上游 PR。仅关联缺失 / 读取失败、多义关联、不完整边界、历史分叉等真实异常暂停。
- 已有台账中明确包含的字段兼容只读，不再作为正常提交的准入条件。旧“明确包含”复选框和确认错误入口移除。
- 初始连接区域包含来源 GitHub 认证、内部平台认证与新接收提交署名；按模式区分实际必需项。普通配置与 Token 分路提交，凭据只留会话内存或已有环境变量，不进入草稿、台账、历史或公开内容。服务重启缺认证时明确提示补充，不假称永久保存。
- 自动同步意图与冻结终点存入原台账，状态至少有 RUNNING / WAITING_REVIEW / FAILED / PAUSED / COMPLETE。任务、交付与目标使用同一绑定，不另存矛盾游标。重复点击回读原意图；旧请求不能启动另一轮。
- 发起动作串联范围扫描、冻结交付、Issue 创建 / 复用、候选准备、检查、推送与 PR 创建，停止在真实平台审核。手工适配器或缺少一次性配置不得被说成全自动；先给出具体配置入口。
- 合入观察由正式服务在后台持有，浏览器关闭 / 切换项目不影响；只读观察内部目标分支，未变化时不重复推送或建单。检测变化后通过项目原 Tasks 执行器登记恢复任务，核验既有候选，按原 Issue 条件关单回读，继续下一笔，直到冻结终点。
- 崩溃重启读原意图与交付；已合入待补元数据先恢复，不重新创建候选或 PR。后台与人工操作沿用同一单写和请求身份规则。读取故障保留待审状态和安全错误，按间隔重试；写入结果不明交由既有原对象恢复规则，不盲目重复创建。
- 服务关闭先停止调度和只读观察，再等待已有执行器安全退出；不删除私有状态。

## 提交身份与额外节点

Git 作者、提交者和平台认证账号分别建模。原始对象保留模式中，上游身份和 SHA 不改；新增接收节点使用可配置的姓名 / 邮箱。旧默认服务身份兼容可解释，不能声称来自 Token。改写原始作者必然产生新 SHA，若用户选择该方式，需要完整内外映射、冻结身份策略、恢复与验收，不能伪称原 SHA。

当前实现会先构造基线衔接节点，再构造接收节点。目标本身已包含上次上游版本，接收节点以内部基线与目标为双亲即可保持两侧祖先，可移除冗余衔接节点。只有内部 HEAD 已是来源目标的祖先且文件规则无需改写时才可直接引用来源目标；独立内部历史或保留路径仍需必要接收节点。平台自己的合入节点单独说明。

用户已确认提供可选重写模式。实现采用 `commitStrategy: preserve | rewrite` 和显式的 `receivingIdentity: {name, email}`。重写模式逐条从来源对象读取消息字节与日期，按拓扑顺序生成内部提交；来源父节点映射到本笔新 SHA 或当前已接受内部基线，不进行三方合并。每个中间文件树也保留声明的内部路径。重复构造得到相同 SHA，映射在候选发布前与交付一起持久化。重写对象不沿用原签名。

关单核验使用内部映射 SHA，不再错误要求外部原 SHA 成为内部祖先。保留模式只产生一个必要接收节点，移除旧的基线衔接节点；已冻结旧候选继续使用，不回写或重建旧历史。版本模式仍是一个内容提交，不伪造逐条映射。

后台观察使用正式服务生命周期和原项目 Tasks 执行器，轮次标识在台账内保存，目标冻结与来源队列原子保存。观察只读内部目标分支；真实变化才登记恢复任务。跨越两笔交付的恢复任务同时记录各笔归属，历史按交付过滤步骤。配置、任务、历史和映射均沿用原目录；不存在迁移、重置或新建空台账替代。

## 界面

始终展示目标与全景阶段，区分自动执行、等待人工审核、异常暂停、完成。只自动展开当前 / 失败阶段；步骤完成后收起旧阶段，保留用户主动展开查看历史的能力。阶段内展示具体子步骤、开始 / 完成时间、PR / commit 来源、内外 SHA 和安全错误，避免再跳另一个窗口找执行记录。主操作随状态变为同步、打开内部 PR、补认证 / 恢复；不要求重复点击准备、创建、核验、关单。

## 验证

按 TDD 先观察自动无 PR、一次点击到待审、真实合入后自动继续 / 关单、关闭浏览器与服务重启恢复、冗余节点数量、身份及 SHA 映射、折叠行为的 RED，再实现。覆盖多项目隔离、重复请求、权限失效、网络中断、回执丢失、保存失败与历史只读。用真实隔离 Git 和平台合同完成自动创建 / 合入 / 关单浏览器旅程；真实来源扫描与快照回放不冒充内网平台验收。原 PR #77 单一分支交付，正式入口保留私有状态，不含演示服务。
