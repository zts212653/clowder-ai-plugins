# 仓库同步用户旅程：实施与验证记录

对应[已批准优化方案](2026-10-15-repo-sync-ux-journey-optimization-plan.md)及[复审取舍说明](2026-10-15-repo-sync-ux-review-response.md)。全部变更交付于 [PR #77](https://github.com/zts212653/clowder-ai-plugins/pull/77) 原分支，不另开 PR，不合入上游。

## 已实施的操作路线

1. **连接与认证**：新项目明确选择模式，两侧地址和分支归属清楚。Git、GitHub 读取认证和内部对象认证分开；普通校验后保存配置、提供 Token，再自动只读检查。失败保留已保存部分及普通草稿，不要求新建项目。
2. **核验已有同步起点**：完成的仓库设置收起。外部输入上次已接收的历史 tag / 完整 SHA，内部读取当前接收分支 HEAD。核验只读，不直接登记起点；即使内容一致也能查看完整文件树。
3. **确认启用**：文件规则重新核验通过后，点击继续，核对汇总，再显式启用。只有最后一步登记接管对应。修改连接会使旧差异报告失效；同一绑定不改值重存保留历史输入。
4. **日常同步**：过程模式选择终点后点击“开始同步”，版本模式选择 tag 后点击“同步到所选版本”。有效自动化配置下自动执行到具体内部 PR，人工合入后自动核验、按条件关单并继续。只读范围预览复用真实规划器，但使用独立内存台账，不发布队列或调用写适配器。
5. **异常与历史**：五阶段中每个真实子步骤只有一行状态；错误和每次尝试跟随该行。完成阶段收起，主动展开不被轮询关闭。历史复用同一流程只读回看，增加 7/30/90 天筛选；旧数据缺项显示未记录。

项目概览仅投影本地台账，不自动扫描其他远端；显示模式、已接收位置、最近观测及需要处理的状态。切换保护普通草稿及未提交 Token。文件树增加 README / 文档查找入口和完整影响数量，筛选不自动写保留规则。

## 保持的内容和恢复边界

- README 三种名称分别声明。只选 README.md 不会保留 README.cn.md；已选且内部不存在的路径保持不存在；目录规则覆盖未来文件。其他核心差异仍在接管或同步前阻断。
- 已启用规则、来源和终点维持原冻结约束。不支持三方合并、自动核心修复、复制项目绕过同一接收分支绑定或重置损坏台账。
- 代码已接受但元数据待处理时恢复原 Issue 关联/关单，不倒退游标或重复推送。无 PR 的明确主干提交继续自动纳入，读取失败不当作无 PR。
- 完整集合冻结前总数未知；旧轮次缺少入场依据也不编造总数。只有 COMPLETE 计入完成，创建 PR 和代码已接收但元数据待处理均不计完成。
- Git 最近报告与任务状态最近成功读取分开显示。30 秒无新 Git 报告和约 5 分钟耗时较长均是提示，不自动取消，不承诺人工合入时间。
- Token 仍仅在服务内存或既有环境变量。刷新/关闭浏览器不清除服务认证，服务重启需重新提供。未提交秘密不写浏览器草稿、配置、任务或台账。

### 完整旅程与故障覆盖

- 版本模式从空项目开始，经过显式模式、普通字段失败保留输入、认证不落浏览器草稿、只读 Git 检查、历史 tag、文件树保留、重新核验、确认启用、只读预览、一键 PR、人工 Git 合入和自动接收。
- 过程模式从空项目开始，初始填写两类 Token、只读检查、历史 tag、README 三路径保留与确认启用。一个目标意图先搬运来源 PR，再搬运明确无 PR 的主干提交；共享 Issue 首笔保持打开、所需范围齐备后关闭。核对逐条身份/SHA 映射、具体 PR、刷新续接及不重复建单。
- 两种只读预览成功及过程来源读取中途失败，均断言真实业务台账深相等、内部 refs 原样、候选构造/检查/推送及对象写适配器零调用。PAUSED 且没有活动交付的原轮次也拒绝新预览。
- 丢新增项目回执、丢同步请求回执、Git 下载取消/停止确认、候选检查失败、PR 引用纠正/撤销、创建/关单回执不明、业务成功但任务记录保存失败、台账保存失败、后台恢复及历史只读均保留原风险断言。
- 1440 / 1024 / 768 / 390px 检查无横向溢出；核验成功后移动端继续按钮可见；轮询保留当前字段焦点/光标及用户展开阶段。

### 独立审查发现与处理

非作者审查发现三类 P2，均已修复并针对旧实现观察失败、针对修复观察通过：

1. 同绑定重存后秘密残留在替换 DOM：请求前同步取走并清空输入；成功不恢复秘密。
2. 同 Git 绑定但 API 配置修订改变时，旧 Token 可能提供给新范围：比较保存回执修订；认证请求在首次异步等待前冻结范围。未提交密码也不能跨修订恢复。
3. 多个 Issue / 不同交付的同名表单串写：按表单类型、来源、交付、原引用及路径匹配；普通焦点/光标仅在同一对象恢复。

私有配置文件树不能勾选、历史输入重存后丢失、摘要重载展开、重复认证表单和手机下一步不可见，均由浏览器回归实际暴露并修复。旧测试选择器根据新流程改为检查实际步骤、业务状态及诊断展开；未删除原恢复断言，未通过放宽超时隐藏错误。
