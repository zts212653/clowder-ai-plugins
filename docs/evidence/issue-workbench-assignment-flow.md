# Issue 工作台：打开即选人、指定分析猫

来源：`thread_mucwsgsjtlbabfcq#0001792553407782-000031-4e6d17f0`。
原问题是人员控件嵌在分析结果内，首次打开问题必须先请求猫才能选人。

现在打开问题自动显示已有分类、Feature 归属及组织成员，可直接选人并确认。
分析入口先选猫，默认发送“问题分类 + 按限制规则指派人员”的任务；自动派工
关闭时任务只能推荐，开启时由插件复核资格、当前来源及权限后执行。
待返回的结果自动刷新，并投影到列表、分类筛选和详情。直接指派单独记账，不虚构研判分数、分析来源或模型统计。

“自动分类”的触发方式已询问，尚无新答复时采用自动展示已有结果、点击才唤醒猫。
没有已有结果的问题明确显示尚未分类，直到所选猫返回；不把规则猜测当模型输出。
